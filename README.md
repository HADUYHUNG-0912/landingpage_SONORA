## Giới thiệu

Sonora đồng hành cùng doanh nghiệp từ phân tích bài toán, xây dựng giải pháp đến phát triển và triển khai sản phẩm số thông qua một quy trình rõ ràng và minh bạch.

- **Dịch vụ trọng tâm**: CRM Development, Web & Mobile Development, Digital Solutions.
- **Triết lý**: Technology starts with understanding.

## Công nghệ sử dụng (Tech Stack)

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: CSS Modules / Vanilla CSS Design System, Radix UI Primitives, Lucide Icons
- **Animation**: Framer Motion (GPU-accelerated transforms & opacity)
- **Deployment**: Vercel

## Hướng dẫn cài đặt & chạy Local

```bash
# Cài đặt thư viện phụ thuộc
pnpm install # hoặc npm install

# Khởi chạy môi trường phát triển local (Port 3000)
npm run dev

# Kiểm tra kiểu TypeScript
npm run check

# Đóng gói Production
npm run build
```
